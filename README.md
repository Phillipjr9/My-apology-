# For Itunuoluwa ❤️ — From Olakunle

A deeply personal, cinematic, romantic website made for Itunuoluwa Ayelabola.

## How to open

Simply open `index.html` in any modern browser (Chrome, Safari, Firefox) on phone or computer.  
It is designed primarily for **mobile**.

## Features included

- Cinematic opening screen with sequential text reveal
- Heartfelt apology section
- “I really like you” declaration with heartbeat
- Animated feeling cards
- “Through my eyes” section
- Interactive floating love cards (tap to highlight)
- Emotional confession section
- “Maybe someday…” hope timeline
- Animated envelope that opens to a full letter
- Playful “Are you still mad?” interactive buttons with celebration
- Cinematic ending
- Floating hearts, particles, sparkles, butterflies
- Soft optional ambient music toggle (no autoplay)
- Fully mobile-optimized

## How to personalize (easy)

1. **Add photos**  
   Insert `<img src="your-photo.jpg" alt="..." style="max-width:90%; border-radius:16px; margin:1rem auto; display:block;">` inside any section.

2. **Change the letter**  
   Edit the text inside the `#letterContent` div.

3. **Add more reasons you like her**  
   Duplicate a `.love-card` or `.feel-card` and change the text.

4. **Replace the soft music**  
   You can add your own romantic song:
   ```html
   <audio id="bgMusic" loop>
     <source src="your-song.mp3" type="audio/mpeg">
   </audio>
   ```
   Then update the play/mute buttons to control `#bgMusic` instead of the soft synthesizer.

5. **Add important dates or memories**  
   Create a new section or add cards in the timeline / love grid.
